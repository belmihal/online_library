# ADR 0001: Выбор технологического стека проекта

* **Статус:** Принято

## Контекст
Требуется создать веб-приложение «Онлайн-библиотека книг» с разделением на Frontend, Backend и реляционную БД, которое легко поддерживать, тестировать и демонстрировать на защите.

## Решение
1. **Backend:** Python 3 + Django 5 + Django REST Framework (DRF).
   * Классическая структура с единым файлом `settings.py` и зависимостями в `requirements.txt`.
   * Автогенерация документации OpenAPI/Swagger через `drf-spectacular`.
2. **База данных:** PostgreSQL (в Docker) с возможностью быстрого локального запуска на SQLite при разработке и тестировании.
3. **Frontend:** Базовый React 18 (JavaScript ES6 / `.jsx`) + сборщик Vite + `react-router-dom`.
   * Используются только стандартные хуки `useState` и `useEffect` и встроенный браузерный `fetch()`.
   * Стилизация на чистом CSS с CSS-переменными для переключения светлой и темной темы и адаптивной версткой (`@media`).
4. **Инфраструктура и тесты:** `pytest` для тестирования бэкенда (покрытие >75%) и `Docker Compose` для запуска проекта одной командой.
