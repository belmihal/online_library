# ADR 0002: Токен-аутентификация и разделение ролей

* **Статус:** Принято

## Решение
1. Для авторизации между React-фронтендом и Django-бэкендом используется токен-аутентификация.
2. При входе (`POST /api/v1/auth/login/`) или регистрации сервер возвращает токен и данные пользователя (`id`, `username`, `role`).
3. Фронтенд сохраняет токен в `localStorage.setItem('token', ...)` и прикрепляет его к HTTP-запросам в файле `src/api.js`.
4. Роли пользователей:
   * `reader` (читатель) — просмотр каталога, взятие и возврат книг, написание отзывов.
   * `admin` (администратор) — добавление и удаление книг, авторов, жанров, массовый импорт книг из CSV.
