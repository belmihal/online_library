# Online Library

Учебный проект: онлайн-библиотека книг.

## Стек

- Backend: Python 3.12 + Django 5 + Django REST Framework + PostgreSQL
- Frontend: TypeScript + React 18 + Vite + React Router + TanStack Query
- Тесты: pytest-django (бэк), Vitest + React Testing Library (фронт)
- Инфра: Docker + docker-compose, OpenAPI через drf-spectacular
- Авторизация: JWT (djangorestframework-simplejwt)
